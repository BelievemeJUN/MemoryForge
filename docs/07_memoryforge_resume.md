# MemoryForge 完整项目简历（面试直接用）

> 写法参考：Agent 项目简历"动词 + 技术 + 量化参数"标准式（每条一句话带数据，不堆虚话）。
> 定位：**强记忆 + 沙箱代码执行** Agent。所有数据真实可查。

---

**项目描述**：面向企业内网，打造一个具备**长期记忆与自愈能力**的代码执行智能体。用户通过自然语言描述编程或数据分析需求，系统自动完成意图理解、方案规划、代码生成、沙箱隔离执行与结果自愈，解决了 AI 生成代码"不可信、不安全、无法闭环"的痛点。项目构建了纵深防御的代码沙箱与基于四类记忆的个性化引擎，并覆盖了认证、限流、成本、可观测、评测等全链路生产环节。

**技术栈**：Python / FastAPI / LangGraph / PostgreSQL / Redis / Milvus / JWT / Docker / SSE

**项目职责**：

1. **对话编排与多子图架构**：采用 LangGraph 手工构建对话状态机，替代传统黑盒 Agent 框架。设计意图路由总图（闲聊 / 代码执行 / 知识检索 / 后台任务四出口）与代码自愈子图（规划 → 编码 → 执行 → 验证 → 修复）。后台任务出口开放对话层闭环——一句话提交任务、查询状态、列表，异步能力以自然语言可达。各子图以独立状态运行、与对话上下文隔离，避免状态污染；修复循环由硬编码熔断机制限制在最多 3 轮，杜绝无限烧钱；会话经 PostgreSQL checkpoint 按 thread_id 持久化，多轮隔离不串台。

2. **纵深防御代码沙箱**：构建六层容器隔离防御体系——默认断网、只读根文件系统、非 root 运行、去除全部 Linux Capabilities、自定义 seccomp 禁用逃逸系统调用、内存/CPU/进程/磁盘精细化配额；叠加容器前 AST 静态审查、镜像白名单与 digest 锁定、Redis 分布式信号量并发控制、孤儿容器自动回收。11 类攻击用例（rm -rf、反弹 shell、读取 /etc/shadow、fork 炸弹、磁盘写满、内存耗尽）全部转化为回归测试并全绿，直接解决"AI 代码不可信、不安全"痛点。

3. **强记忆系统与提示词工程**：设计摘要/语义/情节/程序四类长期记忆，基于本地 BGE 向量 + BM25 稀疏检索 + RRF 融合排序，向量存 Milvus、原始对话与画像存 PostgreSQL；配套结构化记忆提取提示词（模型按 JSON Schema 输出四类记忆并附 importance 打分），并设计"润色版 / 零发散版"双模式系统提示词按场景切换。对话后异步提取、全场景注入；记忆访问时间经 Redis 节流使写放大下降一个数量级；配合容量上限（近似 LRU）、单条删除与低频淘汰，实现记忆库可治理、可遗忘。

4. **确定性验证与双通路路由**：设计"编码 → 执行 → 验证 → 修复"自愈闭环，验证层按任务类型双通道路由——显式期望输出采用确定性比对（精确 / 模糊 / 浮点容差），目标型任务采用 LLM-as-judge 按验收标准判定完成度。110 道自建题库真实评测：一次通过率 77.3%，经自愈循环提升至整体 99.1%（bootstrap 95%CI 97.3%~100%），且硬编码熔断保证成本不失控。

5. **智能成本治理与模型路由**：基于复杂度评估实现三级模型路由——简单任务走轻量模型、复杂任务走高性能模型、验证走专用判定模型，按任务复杂度分配算力；验证层双通道路由（显式期望输出走确定性比对，仅目标型任务触发 LLM-as-judge），避免非必要推理开销；成本可观测采用**OpenTelemetry GenAI 标准指标**（`gen_ai.client.token.usage`，intent/plan/write/fix/judge 全节点自动上报，含 judge 补账），可对接 Prometheus/Grafana；叠加硬编码熔断与 per-user 日预算兜底、长对话滚动压缩、用户画像置上下文尾部命中模型前缀缓存，多措压低 token 开销。

6. **评测与生产保障**：自建 **110 道不重复 Python 题库**（手写 + LLM 生成双源、期望输出自动校验），构建分层评测体系并跑出真实指标——用例级**整体通过率 99.1%**、循环级**一次通过率 77.3%**（自愈循环提升至 99.1%，平均尝试 1.15 轮）、安全级**危险命令 / 逃逸 / 资源滥用三类拦截率均 100%**、成本级**单题平均 306 token**；配套 pytest 90 用例 + GitHub Actions CI、request_id 全链路可观测、JSON 结构化日志、四依赖健康探活（PG/Redis/Milvus/Docker）、沙箱审计落库、JWT 认证（API Key 换短时令牌，user_id 仅取自认证上下文）与多租户命名空间隔离，以及 GDPR 删除权 / 导出权对称实现。
