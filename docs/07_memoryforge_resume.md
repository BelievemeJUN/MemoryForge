# MemoryForge 完整项目简历（面试直接用）

> 写法参考：Agent 项目简历"动词 + 技术 + 量化参数"标准式（每条一句话带数据，不堆虚话）。
> 定位：**强记忆 + 沙箱代码执行** Agent。所有数据真实可查。

---

**项目描述**：面向企业内网，打造一个具备长期记忆与自愈能力的代码执行智能体。用户通过自然语言描述编程或数据分析需求，系统自动完成意图理解、方案规划、代码生成、沙箱隔离执行与结果自愈，解决 AI 生成代码"不可信、不安全、无法闭环"的痛点。项目构建了纵深防御的代码沙箱与基于四类记忆的个性化引擎，并覆盖认证、限流、成本、可观测、评测等全链路生产环节。

**技术栈**：Python / FastAPI / LangGraph / PostgreSQL / Redis / Milvus / JWT / Docker / SSE

**项目职责**：

1. **对话编排与多子图架构**：采用 LangGraph 手工构建对话状态机，替代传统黑盒 Agent 框架。设计意图路由总图（代码执行 / 闲聊 / 知识检索 / 后台任务四出口）与代码自愈子图（编码 → 执行 → 验证 → 修复）。各子图以独立状态运行、与对话上下文隔离，避免状态污染；后台任务出口开放对话层闭环（一句话提交 / 查询 / 列表），异步能力以自然语言可达；修复循环由硬编码熔断限制在最多 3 轮；会话经 PostgreSQL checkpoint 按 thread_id 持久化，多轮隔离不串台。

2. **纵深防御代码沙箱**：构建六层容器隔离防御体系——默认断网、根文件系统只读、非 root 运行、去除全部 Linux Capabilities、seccomp 禁用逃逸系统调用、内存/CPU/进程/磁盘精细化资源配额；叠加容器前 AST 静态审查、镜像白名单与 digest 锁定、孤儿容器自动回收，为不可信的 AI 生成代码建立安全执行边界。

3. **强记忆系统**：检索层面，基于本地 BGE 向量 + BM25 稀疏检索的 RRF 融合排序，联合 Milvus（向量）与 PostgreSQL（父子块）实现结构感知检索；提示词层面，设计摘要 / 语义 / 情节 / 程序四类长期记忆，配套结构化记忆提取（JSON Schema 输出 + importance 打分）与"润色版 / 零发散版"双场景系统提示词切换。实现稳定且可治理的长期记忆——记忆访问时间 Redis 节流（写放大降一个数量级）、容量上限（近似 LRU）、单条删除与低频淘汰。

4. **双通路路由验证**：实现"编码 → 执行 → 验证 → 修复"自愈闭环的验证层双通道路由——显式期望输出型任务采用确定性比对（精确 / 模糊 / 浮点容差）自动判定，目标型任务采用 LLM-as-judge 按验收标准判定完成度；实现验证路由分发模块（确定性优先，仅目标型任务触发一次判定推理，避免非必要开销），并以硬编码熔断控制修复轮数。

5. **智能成本治理**：基于复杂度评估实现三级模型路由（简单 / 复杂 / 验证任务 → 轻量 / 高性能 / 专用判定模型），按任务复杂度匹配算力；验证层双通道路由（确定性优先、仅目标型任务触发 judge）避免非必要推理——A/B 对比实测使验证阶段成本降低 39.9%；采用 OpenTelemetry GenAI 标准指标实现全节点 token 自动上报（intent/plan/write/fix/judge），叠加任务级 / 用户级硬编码熔断与长对话滚动压缩，在保证成本可观测的同时降低 token 开销。

6. **评测与生产保障**：构建五级分层评测体系（真实 LLM + 沙箱跑出）——**答案级**（代码题整体正确率 99.0%，100 题）、**检索级**（RAG 知识库召回率 97.7%，44 题 / 70 篇干扰库 / top_k=1，easy 100% 与 hard 95% 分层）、**循环级**（一次通过率 84%，自愈循环提升至 99.0%，平均尝试 1.18 轮）、**安全级**（危险命令 / 逃逸 / 资源滥用三类拦截率均 100%）、**成本级**（验证路由 A/B 对比使验证成本降低 39.9%）；配套 pytest 90 用例 + GitHub Actions CI、request_id 全链路可观测、JSON 结构化日志、四依赖健康探活、JWT 认证与多租户命名空间隔离、GDPR 删除权 / 导出权对称实现。
